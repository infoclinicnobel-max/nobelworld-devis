DÉPLOIEMENT GITHUB / NETLIFY
----------------------------
1. Placez TOUS ces fichiers à la RACINE du dépôt GitHub
   (au même niveau qu'index.html), en remplaçant les anciens.
2. Si votre dépôt contient un sw.js : ouvrez-le et incrémentez la
   version du cache (ex. 'cn-v1' -> 'cn-v2'), sinon ignorez ce point.
3. Poussez : Netlify redéploie automatiquement.

CE QUE CONTIENT CETTE VERSION (rappel des sprints)
--------------------------------------------------
- PDF 2 pages garanti (pagination 287 mm, en-tête compact, alerte de débordement)
- Nom de fichier PDF : « Clinic NobelWorld — Devis/Facture — NOM Prénom »
- Synchronisation blindée : safeMerge anti-écrasement, snapshot local par
  utilisateur, bannière hors-ligne, timeout 45 s
- Correction date d'opération (décalage fuseau Google Sheets neutralisé)
- Paramètres -> Textes PDF (tous les textes du PDF modifiables + priorité
  document -> paramètres -> défauts + bouton « Appliquer les paramètres »)
- Remise promotionnelle (€ ou %, motif, total/acompte/solde recalculés)
- Recherche globale corrigée (téléphones numériques) + ErrorBoundary
- Paramètres -> Permissions utilisateurs (26 permissions, préréglages,
  rôles Lecture seule et Utilisateur limité, PDG inverrouillable)
- Boutons « + Ajouter une facture » et « + Ajouter un paiement »
  (facture depuis devis ou manuelle, paiements typés, statuts auto)
- Anti-fermeture accidentelle des formulaires + confirmation
  « modifications non enregistrées »
- Logo CN officiel : sidebar, connexion, favicon, icônes PWA
